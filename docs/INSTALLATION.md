# Installation and Run

## Install
```bash
git clone https://github.com/ZieganWesley/Private_Agent.git
cd Private_Agent
pip install -e .
```

## Run
```bash
private-agent
```

## Diagnostics
```bash
private-agent --doctor
```

## UI Check (developer only)
```bash
private-agent --ui-check
```
Remove this trigger before production.
