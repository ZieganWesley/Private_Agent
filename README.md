# Private Agent

Local-first, privacy-focused terminal AI agent with permission-gated tools,
local RAG, skills, and persistent memory.

## Quick Start
- Install: see [docs/INSTALLATION.md](docs/INSTALLATION.md)
- Run: `private-agent`
- Diagnose: `private-agent --doctor`
